# House Price Prediction

A full-stack house price prediction project using:

- Python
- FastAPI
- Scikit-learn
- React
- TypeScript

## Model File

The trained model file is available here:
https://drive.google.com/your-file-link

## Backend

The FastAPI backend provides:

- GET /health
- POST /predict

## Frontend

The React frontend provides a prediction form for house features and displays the predicted price.

The trained machine learning model is loaded from:
